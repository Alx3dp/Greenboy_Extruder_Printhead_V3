# Greenboy_Extruder_Printhead_V3
An Alternative Printhead design for the Greenboy Pellet extruder

This toolhead brings many quality of life improvements like removable pellet hose connetor, easier assembly, more compact design, minimal disassembly required to pull the screw which can be performed with the printhead still attached to the printer and similar improvements.
One caveat of that is that you will have quite a bit less height available, you will loose up to 70mm. THis can however be fixed with a custom mounting plate provided you do not need a z probe or are able to figure out a non standard mount for it.

As this design uses a seperate mounting plate between the printer and the printhead you only need to edit that to use it on a not yet supported printer, same with using another z probe for which there are 3 mounting holes in the mounting plate.

I have now uploaded the 3.1 version, it has significant changes to a few parts of the printhead. 
If you currently use the V3 you can just print the 3 parts that have changed and a new mounting plate for it, if you wanna use the V3.1 directly there is also an stl for that.
The V3.1 gives up the easy access to the screw for internal inlet geometry and a big rotating inlet guide that should make the pellets flow towards the inlet better and so make the overall flow of the extruder a bit more consistent.
I recommend using it with the soft screw as I've still had jamming issues at the inlet of the normal screw.
I have not made a new assembly guide for the V3.1, most things carry over from the V3, if you have any issues contact me on discord or per mail as said below.
